## 0. 关键决策

| 项 | 决定 |
|----|------|
| 存储 | **Neon Postgres**（Vercel Marketplace 免费档），`DATABASE_URL` 仅服务端 env |
| 访问层 | Drizzle ORM + `@neondatabase/serverless`；迁移文件进仓库 `db/migrations/` |
| 金额精度 | DB 用 `numeric`，计算用 `decimal.js`；**禁止 JS float 参与金额计算** |
| 本位币 | **JPY**。外币持仓按快照时录入的汇率折算；V1 不接行情/汇率 API |
| 数据来源 | 手动录入 / SBI CSV 导入 / 截图（Grok Bot 识别后确认，再经写入接口落库） |
| 读权限 | 仅登录会话（白名单 niqinou@gmail.com），服务端读，`Cache-Control: no-store` |
| 写权限 | 会话（手动、CSV） + 专用写入密钥（截图结果，仅能写资产数据，不能读） |
