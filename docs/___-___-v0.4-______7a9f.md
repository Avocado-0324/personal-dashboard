# 个人聚合页 体验稿 v0.4：视觉升级 + 持仓板块（已定：默认 B 午夜深色，2026-10-05）

效果图（示例数据）：`/workspace/docs/A_light.png`、`B_dark.png`、`P_page.png`（同名 .html 可直接打开，CSS 可参考）

## 1. 视觉方向（用户已选 B 为默认；A 作为浅色主题保留）
- **A 柔光浅色**：浅灰底 + 淡紫/粉径向渐变，半透明白卡片（backdrop-blur），柔和阴影，圆角 22–24px，主色 indigo #4f46e5。
- **B 午夜深色**：#0a0b0f 底 + 青/绿弱光晕，深色卡片 1px 描边，主色 cyan #22d3ee、涨色 lime #a3e635。
- 共用：Inter + Noto Sans CJK（JP），数字等宽（Geist Mono / IBM Plex Mono，`tnum`）；跌色 #e11d48；顶栏右侧「主题」切换（深 / 浅 / 跟随系统），默认深色 B，存 cookie；首屏按 cookie 服务端渲染，避免闪白。

## 2. 首页布局
- 顶部 **总览区**：日期、问候语「上午/下午/晚上好，Qinou」、一句摘要（未读数、GitHub 本周活动数）。持仓模块开启且有数据时，右侧显示 总资产 / 累计盈亏 / 年化 XIRR；关闭则不显示（不占位）。
- 桌面两栏（≥1024px）：左 = 邮件待办、GitHub；右 = 持仓、育儿 Tips。移动端单栏顺序：总览 → 邮件 → 持仓 → 育儿 → GitHub。
- 卡片头统一：图标块 + 标题 + 次要说明 + 右侧单个文字操作。
- 邮件：头像首字母、未读数徽标、「需回复」黄色标签、「打开 Gmail ↗」。
- GitHub：三格统计（提交/PR/审查）+ 7×2 活跃色块 + 最近 2 条中文动态（「推送了 N 个提交」「合并 PR #N」）。
- 育儿：保持 1–3 条、「今日」、「换一批」、主题标签。

## 3. 持仓
- **首页卡片**：快照日期、前 3 大持仓（名称、账户、市值、盈亏%）、按账户分布条（NISA 成长 / NISA 积立 / 特定 / 现金）。右上「＋ 录入 · 明细 →」进 `/portfolio`。总资产数字放总览区，卡片内不重复。
- **录入放独立页 `/portfolio`**（不放设置子页：设置只管开关和配置，持仓是浏览 + 编辑数据）。
  - 顶部 Tab：持仓 / 入出金 / 快照历史 / 导入记录；右侧 KPI：总资产、累计盈亏、年化 XIRR、现金。
  - 持仓表：名称/代码、账户标签、数量、平均成本、现价、市值(JPY)、盈亏%；点行编辑；外币注明快照汇率。
  - 右栏「更新数据」：CSV 拖入区（出错标行号）、截图说明（发 Grok 私聊，确认后写入）、手动新增。
  - 导入记录里每批可「撤销整批」（危险样式 + 二次确认）。
- **空/异常态**
  - 模块关闭：首页无卡片、总览无资产数字。
  - 开启但无数据：卡片显示「还没有持仓数据」+ 按钮「去录入」+ 小字「支持手动、SBI CSV、截图」。
  - XIRR 不可算：显示「数据不足」，hover 说明「需要至少一笔入金且满 30 天」。
  - 数据库未配置：卡片和 `/portfolio` 显示「数据库未配置」+ 小字「配置后即可录入」，不报错不崩。
  - 缺少汇率：该条持仓行显示「缺少汇率」黄色标签 + 「补汇率」操作；总览/卡片总资产旁显示「有 N 条未计入」，不按 0 算。
  - CSV 出错：列出「第 N 行：原因」，可下载错误清单；部分成功时明确写「已导入 X 行，跳过 Y 行」。
- 金额显示：日元整数加千分位；盈亏带正负号和颜色；不要用红绿以外的含义色表示涨跌。

## 4. 实现约束
- 先做视觉 PR（只改样式/布局，不动业务逻辑），再做持仓 PR。
- 示例数据只在 demo 模式出现，生产不可见。

## 5. 样式 PR 体验验收要点（B 深色）
- 背景 #0a0b0f，卡片 #111318 + 1px #1f232c 描边，圆角 22px；正文 #e5e7eb，次要 #8b93a3；对比度 ≥ 4.5:1。
- 主色 cyan #22d3ee（链接、徽标、焦点环），涨 lime #a3e635，跌 #f87171（深色下用浅一点的红）。
- 所有数字等宽 `tnum`；按钮/链接有 hover 与 `:focus-visible`。
- 卡片顺序由 manifest `layout.column` 决定；移动端单栏顺序：总览 → 邮件 → 持仓 → 育儿 → GitHub。
- 原有状态（未连接/去连接、空态、错误重试、换一批、刷新）在深色下都要可读，不能沿用浅色的 bg-red-50 等。
