## 0. 体验约束

| 项 | 约定 |
|----|------|
| 首页 | 顶栏「我的聚合」+ 设置；**单列**卡片流 |

## 2. 运行时

```ts
export type UserSettings = {
  onboardingCompleted: boolean;
  modules: Record<ModuleId, { enabled: boolean }>;
  config: {
    'parenting.ageBand'?: '0-6m' | '6-12m' | '1-2y' | '2-3y' | '3y+';
    'parenting.themes'?: Array<'sleep' | 'feeding' | 'play' | 'health' | 'emotion'>;
  };
};

export type ModuleContext = {
  settings: UserSettings;
  connectors: Partial<Record<ConnectorId, { ready: boolean; displayName?: string }>>;
};

export type ModuleStatus = 'ok' | 'unconfigured' | 'disconnected' | 'empty' | 'error';

export type ModuleLoadResult<T> =
  | { status: 'ok'; data: T; fetchedAt: string }
  | { status: 'unconfigured' }
  | { status: 'disconnected'; connector: ConnectorId }
  | { status: 'empty'; hint?: string }
  | { status: 'error'; message: string; retryable: true };

export type ModuleContract<T> = {
  manifest: ModuleManifest;
  load(ctx: ModuleContext): Promise<ModuleLoadResult<T>>;
  Card: React.ComponentType<{ result: ModuleLoadResult<T>; onRefresh: () => void }>;
};
```

整页：`onboardingCompleted === false` → 首次配置流。  
壳层对 enabled 模块 `Promise.allSettled`；单卡失败不影响其他。

## 3. 数据模型与模块规则（冻结）

### 3.1 mail-todos

**筛选（V1 定死）**：仅 **收件箱未读**。不做星标、不做标签、不做可配置筛选。  
`needsReply`：可选启发式标记，**不参与**筛选。  
「查看全部」→ Gmail 收件箱（或未读视图）deep link。

```ts
export type MailTodosData = {
  totalCount: number;
  items: Array<{
    id: string;
    from: string;
    subject: string;
    receivedAt: string;       // ISO；Card 格式化为相对时间
    needsReply?: boolean;
    deepLink: string;
  }>;                         // 最多 5 条
};
```

### 3.2 parenting-tips

**V1 UI**：不做今日/本周切换；固定 `period: 'today'`；卡片头可静态写「今日」。  
模型保留 `period` 字段供后续；本周切换 ≥ v0.3。「换一批」保留。

```ts
export type ParentingTipsData = {
  period: 'today';             // V1 字面量固定
  items: Array<{
    id: string;
    title: string;
    summary: string;
    theme: 'sleep' | 'feeding' | 'play' | 'health' | 'emotion' | 'general';
  }>;                         // 1–3 条
  personalized: boolean;
};
```

跳过配置 → `personalized: false`，仍可 `ok` + 默认池。内容源 V1：静态 JSON。

### 3.3 github-activity

```ts
export type GithubActivityData = {
  windowDays: 7;
  summary: { commits: number; pullRequests: number; reviews: number };
  items: Array<{
    id: string;
    repo: string;
    type: 'commit' | 'pr' | 'review' | 'issue' | 'other';
    title: string;
    at: string;
    url: string;
  }>;                         // 最多 3 条
  login: string;
};
```

## 4. 刷新与缓存

| 模块 | TTL | 特殊 |
|------|-----|------|
| mail-todos | 90s | 卡片刷新 |
| parenting-tips | 5min | 「换一批」bypass 缓存 |
| github-activity | 120s | 卡片刷新 |

关模块不 load；再开立即 load；无后台轮询/推送。`ok` 必带 `fetchedAt`。

---

## 5. 安全

允许：已授权 Gmail/GitHub 只读；本地存开关与育儿偏好。  
禁止：网银/密码/OTP；token 进客户端；邮件正文/Authorization 入日志；模块互 import server。  
映射：未连接 → `disconnected`；已连 API 失败 → `error`；0 条 → `empty`。

## 7. 验收对照（摘要）

- 开关关闭：DOM 无占位、网络无该模块请求  
- 仅收件箱未读；≤5 条；查看全部进 Gmail  
- 育儿无 period 切换；有「换一批」；头「今日」  
- GitHub 7 天摘要 + ≤3 活动  
- 断连/空/错误卡级隔离  
- 无网银相关代码路径
